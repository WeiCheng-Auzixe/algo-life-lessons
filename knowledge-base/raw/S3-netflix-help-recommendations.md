# 擷取筆記（改寫，不是原文）
- 使用的訊號：你的互動（觀看紀錄、對其他片的評分）、口味相近的其他會員看什麼、片子資訊（類型、分類、演員、年份）、情境（時段、偏好語言、使用的裝置、看了多久）。
- 不使用：年齡、性別等人口統計資料不參與決策。
- 排序：個人化發生在好幾層——哪一列出現（例如「繼續觀看」）、列裡有哪些片、片的順序；最推薦的放在最上面、每列最左邊。
- 新會員：可以先挑幾部喜歡的片「暖機」；跳過的話會看到多樣的熱門片；開始看片後，實際行為會蓋過初始選擇，而且近期行為比舊行為重要。
- 持續改進：每次造訪的回饋（點開哪些、有沒有看完、評分）都用來更新演算法。
- 名詞：演算法＝電腦解決問題時遵循的一組規則。
