# S8｜Google Play：廣告 ID（Advertising ID）

- **類型**：官方說明（Play Console Help）
- **原始筆記**：`raw/S8-google-advertising-id.md`
- **網址**：https://support.google.com/googleplay/android-developer/answer/6048248

## 一句話摘要
Android 手機有一個廣告專用的識別碼，使用者可以重設或刪除；刪除後 App 只會讀到一串 0。

## 重點
- 設定路徑見 [隱私自保](../concepts/privacy-self-defense.md)。
- 頁面沒有明說開發者必須遵守使用者的重設或刪除。
