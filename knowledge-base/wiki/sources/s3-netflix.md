# S3｜Netflix 說明中心：推薦系統如何運作

- **類型**：官方說明頁
- **原始筆記**：`raw/S3-netflix-help-recommendations.md`
- **網址**：https://help.netflix.com/en/node/100639

## 一句話摘要
Netflix 用你的觀看行為、口味相近的會員、片子資訊和觀看情境來排序，**不使用年齡和性別**。

## 重點
- 訊號：觀看紀錄與評分、相似會員、片子資訊、時段／語言／裝置／看了多久（見 [訊號與足跡](../concepts/signals-and-footprints.md)）。
- 個人化發生在「哪一列、列裡有哪些片、片的順序」好幾層。
- 新會員可先挑幾部片暖機；之後實際行為優先，近期行為比舊行為重要（見 [冷啟動](../concepts/cold-start.md)）。
